## The entry

One letter: **K** — for *knackered*. KO'd, kaput, done in after a long day of grinding. Vivid, funny, and true.

The program writes exactly one byte, `K` with no newline, to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run it

```sh
node main.ts
# or, with an explicit output dir:
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Deterministic: every run writes the identical single byte.

## Why K

The judge sees a single letter and imagines the word behind it. The brief's own examples — A for amazing, F for Friday-feeling, Z for zero sleep — are the obvious picks, and the obvious picks are where everyone else crowds. K is the sharper one: every day-word behind it (knackered, knocked out, kaput) means the same thing, spent but still standing, and none of them is vague. It is vivid (you can picture it), funny (slang with a punch), and true (an honest report of a long day, not a performance).
